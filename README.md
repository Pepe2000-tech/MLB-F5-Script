# MLB Betting Hub — V3.2

## Módulos
### Primeras 5
- Mantiene el modelo F5 V3.1.
- ML + hasta 3 líneas de totales.
- Edge, EV, cuota justa, PASS/LEAN/PLAY/STRONG.

### Juego completo (BETA)
- Money Line y total.
- Usa ofensiva, starter, parque y clima.
- Aún NO modela bullpen detalladamente.
- No emite STRONG PLAY.

### Player Props (BETA)
- Pitcher Ks: 4+, 5+, 6+, 7+.
- Hits: 1+, 2+.
- Total Bases: 1+, 2+.
- HRR: 2+.
- Home Run: 1+.
- Genera recomendaciones automáticas sin momio.
- Luego el usuario introduce el momio decimal real.
- Calcula EV y cuota justa.

# MLB F5 Model — V3.1

Exclusivo para Primeras 5 Entradas.

## Novedades
- Consulta automática de lineups mediante MLB boxscore.
- Estados: confirmado, parcial o no disponible.
- Refresco automático aproximadamente cada 2 minutos.
- Muestra los 9 bateadores y el orden al bate.
- Busca OPS vs RHP/LHP cuando MLB devuelve el split con muestra suficiente.
- Si el split no está disponible, usa OPS de temporada.
- Lineup strength entra en la proyección F5 de forma conservadora.
- Sin ambos lineups confirmados no puede existir STRONG PLAY.
- Calidad de datos penaliza lineups faltantes.
- Recomendación se marca como provisional cuando falta lineup.

# MLB F5 Model — V3

Exclusivo para Primeras 5 Entradas.

## Novedades
- Pitcher: ERA, WHIP, K/9, BB/9, HR/9.
- Ajuste conservador por tamaño de muestra del abridor.
- Park factor por estadio.
- Clima automático con Open-Meteo.
- Hasta 3 líneas de totales F5.
- Money Line F5.
- Ranking por EV.
- Calidad de datos separada de confianza del pick.
- Reglas más conservadoras para PLAY / STRONG PLAY.

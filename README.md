# MLB Betting Hub V4.2

V4.2 conserva el flujo simple de V4.1 y vuelve a mostrar el contexto completo del partido al inicio.

## Nuevo
- Contexto visible antes del análisis:
  - equipos
  - pitchers y métricas
  - estadio
  - clima
  - lineups de 9 bateadores cuando MLB los publique
  - estado de lineups
  - calidad de datos
- Botón `🔄 Actualizar datos`
  - limpia caché
  - vuelve a consultar MLB y clima
  - actualiza pitchers, lineups y demás información
- Botón `🤖 Analizar partido`
  - genera el Top de oportunidades
- Cambiar de partido o fecha obliga a realizar un análisis nuevo.
- El refresco automático aproximado de 2 minutos se conserva.

La Pantalla 2 sigue evaluando los momios de Draftea solamente después del análisis.
